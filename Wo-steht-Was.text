2. management.py

Zeile 10 - 104: Benutzer Logik

    -Erstellt einen neuen Benutzer
    -Nur Buchstaben und Zahlen beim Benutzernamen erlaubt
    -Benutzername muss mindestens 3 Zeichen lang sein
    -Prüfen, ob ein Leerzeichen im Passwort ist
    -Passwörter abgleichen
    -Auswertung der Ergebnisse
    -Prüft ob Benutzer schon existiert
    -Loggt den Benutzer ein
    -Findet die ID eines Benutzers
    -Findet die ID einer Kiste
    -Benutzer löschen
    -Kisten löschen

Zeile 105 - 172: Inventar Logik

    -Fügt Kisten hinzu oder updatet die Menge/Preis
    -Löscht eine komplette Kisten-Position
    -Holt alle Items für die Liste
    -Sortierung
    -Holt alle Kisten-Namen aus der Datenbank für das Menü

Zeile 172 - 300: Berechnungen

    -Berechnet aktuellen Wert
    -Berechnet ausgegebenes Geld
    -Addiert alle Kistenmengen
    -Gewinn oder Verlust in Euro
    -Gewinn in Prozent
    -Berechnet Historie für Chart.js
    -Hole die letzten 7 Tage
    -Wenn die Datenbank noch komplett leer ist, brich ab
    -Die Liste umdrehen (ältestes Datum zuerst, für das Diagramm von links nach rechts)
    -Berechne den Portfoliowert für jeden dieser Tage
    -Führe die Berechnung für den aktuellen Tag aus
    -Wert runden und in die Liste für das Diagramm eintragen
    -Bündelt alle Werte für die Routen in main.py

Zeile 300: STEAM API

    -Nimmt die Liste von den Kisten und packt jede einzeln in die Datenbank
    -Liest die Kistenpreise aus
